# DESIGN MODULE PROMPT
**File**: `prompts/02-architecture/design-module.md`  

When designing a new vertical or core capability:
1. Define the module boundary and private schema ownership.
2. Establish explicit domain contracts and integration events.
3. Map granular permissions required for each operation.
4. Ensure zero coupling with internal implementation details of other modules.
5. Create an Architecture Decision Record (ADR) in `/specs/decisions/`.
