# SPEC-DRIVEN FEATURE IMPLEMENTATION PROMPT
**File**: `prompts/03-implementation/implement-feature.md`  

When implementing a feature:
1. Identify and list the relevant `/specs` files.
2. Inspect existing codebase files and perform gap analysis.
3. Formulate the minimal compliant implementation plan.
4. Implement database migrations, Go domain services, and Echo API handlers.
5. Implement React UI components with `<Can>` permission gates and error/loading states.
6. Write unit, integration, and tenant isolation tests.
7. Verify all test suites pass.
